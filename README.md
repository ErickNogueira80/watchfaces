# Mostradores · Galaxy Watch4

Galeria dos mostradores criados por Erick Nogueira para o Galaxy Watch4 (450×450), animados e com a hora real.

**Ver:** https://ericknogueira80.github.io/watchfaces/

- `index.html`: a galeria
- `faces/`: uma página por mostrador
- `dc-mini.js`: motor mínimo que roda os desenhos fora do editor
- `src/`: os desenhos originais; `build.js` gera a galeria a partir deles (`node build.js`)
